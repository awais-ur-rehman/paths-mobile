# Profile redesign

The owner supplied exact composition references and asked for implementation, delegating routine design choices. Preserve Paths typography/colors/icon family and all existing authorization, private-image and relationship rules. Android only; no installs, iOS build, emulator or phone operation. Keep PR16 draft for owner testing.

Use a single portrait-led profile composition for own/member views. The authenticated avatar fills the hero background; the lower half gradually blends a blurred copy of the same decoded image into dark ink. Identity begins around the viewport midpoint: centered name, username, then verification and visibility side by side (wrapping only for accessibility). Bio is plain text. No invented social counts or unsupported actions. Own profile has no message/connect/edit button on its surface. A custom Settings icon at the top right opens a separate white Settings and activity screen. Other members have the custom back arrow at the top right; reporting remains available in the member action area. Existing connection state controls decide when Message, Connect, Accept, Cancel and other real actions are available.

Settings uses the Instagram reference's searchable grouped rows with Paths original icons and generous spacing. Include only implemented destinations: edit profile/privacy, verification, sign-in methods, location, notifications, blocked accounts, reviews, account deletion and sign out. Keep recovery access to settings even if the profile summary fails. Routes remain authenticated/adult/setup guarded.

Below the identity/bio is a two-column photo grid with rounded tiles, actual authenticated post photos, private/empty/loading/error states, lazy slivers and cursor paging. No permanent Posts/refresh row; use pull-to-refresh and inline failure retry. Preserve post detail, moderation and deletion. The blur reuses one decoded private image, never global image cache or a second network request. At large text/keyboard/small widths, content scrolls and labels wrap. Source artwork and tests are retained.
