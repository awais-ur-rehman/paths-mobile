# Task5: consent-aware ingestion

Baseline: implementation plan Task5, TRD3/4.1/4.3, app-flow permission sequence. Existing approved native capture/queue is retained and extended; no dependency, SDK or service installation. Work on feature/location-ingestion in existing clean checkouts.

1. Test backend batch/time/coordinate/authorization/old lease/duplicate/sequence/concurrency/control races and24h retention on real PostgreSQL.
2. Add migration for account pause flag, device identity, scoped leases and PostGIS samples. Full adult session grants a24h location-only HMAC credential bound to user, account session, device session and consent epoch. Native stores it in memory only; no account bearer/refresh secret enters the tracker. New active lease revokes previous. Expected consent epoch prevents a delayed grant from undoing pause; requestId makes grant replay idempotent. Native stop can stop only its own current lease; old stop cannot revoke another device.
3. Validate up to50 samples, timestamps in[-15min,+30sec], finite coordinates/accuracy, current lease/epoch; dedup stable IDs and sequence. Commit sample+one matching outbox event in same transaction. Persist historical-only when older120sec or establishment clock offset>30sec. Retain at most24h; worker purges bounded batches and stale matching intents. Task6 will implement matching; Task5 leaves live match events explicitly pending rather than fake completion.
4. Extend native uploader endpoint policy (HTTPS, debug loopback only), scoped credential/expiry, receipt ACKs, redirect refusal, bounded retry and reachability callbacks. Keep encrypted200-sample/15min queue, generation checks, immediate pause/logout purge and no resurrection after process death. Foreground permission first; coarse is reduced accuracy; background requires separate user action and honest OS limits. Android notification permission separately requested; no emulator/device operation.
5. Build typed location repository/control service with durable pending-pause flag. Local stop invalidates generations/cancels work before awaiting network; resume reconciles remote pause and uses expected epoch before obtaining a new lease. Add disclosure/status/permission page from own profile; no fake Home/encounters or location collection before explicit consent. Selective UI state; native continues independently of a mounted Flutter page.
6. Export real OpenAPI and regenerate both consumers with tested array/ref support where required. Run full tests, native offline builds, real API/worker smoke and one fresh branch review. Fix findings, push draft PRs and give focused physical permission/offline/kill retest. Do not close Task5 or advance dependent Task6 gate before owner results.

Rulings:24h scoped upload credentials avoid duplicating account refresh in native layers; they expire, are hash-only in DB, and cannot authorize any other API. Queue never stores account or lease credentials. Pausing cannot recall an already committed pre-pause observation; ordered epochs reject delayed post-pause batches and controls. There is no OS scheduling or force-stop resurrection guarantee. No public pilot or real personal-data upload is authorized.
